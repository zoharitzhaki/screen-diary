# יומן מסך (Screen Diary) - סרטים וסדרות

אפליקציית ווב אישית למעקב אחרי סרטים וסדרות שצפית בהם: לכל כותר מוצגים כל
השחקנים עם תמונה מהסרט/מהסדרה, מתי הוא שודר/יצא לראשונה, ומתי צפית בו.
הנתונים (שחקנים, תמונות, תאריכים) מגיעים מ-[TMDB](https://www.themoviedb.org)
בזמן שאתה מוסיף כותר חדש.

## חשוב לדעת לפני שמתחילים

- זו אפליקציה בלי מערכת התחברות אמיתית. יש הגנת קוד-גישה בסיסית אחת
  (`APP_PASSCODE`) שסוגרת את כל האתר מאחורי קוד אחד משותף - זה מספיק כדי
  שגוגל ובוטים אקראיים לא ימצאו את זה, אבל זו לא הגנת אבטחה אמיתית. אל תשמרו
  בה מידע רגיש.
- הסביבה שבה נכתב הקוד חסומה מבחינת רשת לרג'יסטרי של npm (מדיניות ארגונית),
  אז **לא הרצתי בפועל `npm install` / `npm run build`** של הפרויקט המלא. כן
  הרצתי type-check עם TypeScript שהיה זמין לי מקומית על כל קובצי הקוד (בלי
  הספריות עצמן), וזה תפס ותיקן באג טיפוסים אמיתי אחד; לא נמצאו שגיאות
  תחביר. זה לא תחליף להרצה אמיתית - יש להריץ `npm install && npm run build`
  פעם ראשונה אצלכם כדי לוודא שהכל עולה, ולתקן אם בכל זאת יצוץ משהו.

## שלב 1: מפתח TMDB (חינמי)

1. הרשמה ב-<https://www.themoviedb.org>.
2. הגדרות → API: <https://www.themoviedb.org/settings/api> → בקשת "API Key
   (v3 auth)". זה מיידי וחינמי לשימוש לא-מסחרי.
3. שימו את המפתח בקובץ `.env.local` (ראו שלב 3).

TMDB דורשים קרדיט: האפליקציה כבר מציגה למטה בכל עמוד "הנתונים מגיעים
מ-TMDB" עם קישור, כנדרש בתנאי השימוש שלהם.

## שלב 2: מסד נתונים ב-Turso (חינמי)

בפיתוח מקומי אפשר לדלג על זה - האפליקציה תיצור קובץ SQLite מקומי לבד.
לפרודקשן (כדי שהאתר יהיה נגיש מהטלפון) חובה מסד נתונים אמיתי:

```bash
curl -sSfL https://get.tur.so/install.sh | bash   # התקנת turso CLI (לינוקס/WSL/מק עם brew: brew install tursodatabase/tap/turso)
turso auth signup                                  # או turso auth login אם כבר יש חשבון
turso db create screen-diary
turso db show screen-diary                        # מציג את ה-URL (מתחיל ב-libsql://)
turso db tokens create screen-diary                # יוצר טוקן גישה
```

שימו את ה-URL וה-token ב-`.env.local` / במשתני הסביבה של Vercel.

## שלב 3: הרצה מקומית

```bash
npm install
cp .env.example .env.local
# פתחו את .env.local ומלאו לפחות TMDB_API_KEY
npm run dev
```

פתחו <http://localhost:3000>.

## שלב 4: פריסה (deploy) ל-Vercel כדי שיהיה נגיש מהטלפון

1. יצירת repo ב-GitHub והעלאת הקוד אליו (`git init && git add . && git commit`
   ואז חיבור ל-repo מרוחק ו-`git push`).
2. ב-<https://vercel.com>: New Project → מחברים את ה-repo מ-GitHub. Vercel
   מזהה אוטומטית שזה פרויקט Next.js.
3. במסך ההגדרות, לפני הפריסה הראשונה (או אחר כך תחת Settings → Environment
   Variables), מגדירים:
   - `TMDB_API_KEY`
   - `TURSO_DATABASE_URL`
   - `TURSO_AUTH_TOKEN`
   - `APP_PASSCODE` (מומלץ - קוד גישה משלכם, כל דבר שתבחרו)
4. Deploy. Vercel ייתן כתובת ציבורית (משהו כמו
   `screen-diary-xyz.vercel.app`) שנגישה מכל מקום, כולל מהטלפון.

## מבנה הפרויקט

```
src/
  app/
    page.tsx              עמוד הבית - רשת התמונות של כל מה שראיתם, עם מיון
                          לפי תאריך צפייה / תאריך יציאה
    add/page.tsx          חיפוש והוספת כותר חדש
    title/[id]/page.tsx   עמוד פרטים לכותר: כל השחקנים/במאים, כל תאריכי
                          הצפייה (אפשר כמה, למשל צפייה חוזרת), עריכת
                          דירוג/הערות, הוספת תאריך צפייה נוסף
    person/[id]/page.tsx  עמוד אדם (שחקן/במאי/ית): כל מה שצפיתם בו + כל
                          הפילמוגרפיה שלו לפי TMDb עם הוספה מהירה לכותרים
                          שעדיין לא ברשימה
    people/page.tsx        רשימת כל השחקנים/במאים שכבר ברשימה
    login/page.tsx        מסך קוד הגישה
    api/                  נקודות קצה: search, titles, titles/[id],
                          titles/[id]/watches, titles/[id]/watches/[watchId],
                          login
  lib/
    tmdb.ts               עטיפה סביב TMDb API
    db.ts                 חיבור למסד הנתונים (Turso / SQLite מקומי) והסכמה
    dates.ts              עזרים לתאריך צפייה עם דיוק גמיש (יום/חודש/שנה)
  proxy.ts                הגנת קוד הגישה (APP_PASSCODE)
```

## הוספת כותרים ידנית

לוחצים "+ הוספת כותר", מחפשים לפי שם, בוחרים את התוצאה הנכונה (סרט/סדרה),
ממלאים תאריך צפייה (אפשר לבחור בין תאריך מדויק, חודש ושנה, שנה בלבד, או לא
לציין תאריך כלל), ואופציונלית דירוג והערות, ושומרים. האפליקציה שולפת
מ-TMDb את כל השחקנים (עד 24 הראשונים לפי סדר הופעה), התמונות שלהם, הבמאי/ים
או היוצר/ת, ותאריך השידור/היציאה הראשון, ושומרת הכל אצלכם.

## עריכה, צפייה חוזרת, וקישור בין אנשים

- בעמוד של כל כותר אפשר לערוך את הדירוג וההערות בכל זמן, ולהוסיף עוד תאריך
  צפייה (למשל אם צפיתם שוב) או למחוק תאריך צפייה בודד.
- לחיצה על שם של שחקן/ית או במאי/ית בעמוד הכותר פותחת את עמוד האדם: משם
  רואים את כל מה שצפיתם בו עד כה, ומתחת לזה גם את שאר הפילמוגרפיה שלו לפי
  TMDb עם כפתור "+ הוספה לרשימה שלי" לכל כותר שעדיין לא ברשימה.
- עמוד "שחקנים ובמאים" (בתפריט העליון) מציג את כל האנשים שכבר ברשימה,
  כמענה לבקשה לשליפה "לפי שחקנים/במאים".

## כוכבית מועדפים, סוג כותר, ומיון בעמוד הבית

- כוכבית (★) ליד כל כותר (בעמוד הבית, בעמוד הכותר, ובעמוד האדם) מסמנת
  "ממש אהבתי את זה". לחיצה עליה משנה את הסטטוס מיד, בלי לפתוח את הכותר.
- כל כרטיס כותר מציג תגית קטנה בפינת הפוסטר אם זה סרט או סדרה.
- בעמוד הבית אפשר לשלב שלושה בקרים באופן עצמאי: מיון (תאריך צפייה / תאריך
  יציאה), כיוון (מהחדש לישן / מהישן לחדש - "כרונולוגי"), וסינון להצגת רק
  המועדפים.
- באותו אופן, לב (❤) ליד כל שחקן/ית או במאי/ית (בעמוד כותר, בעמוד "שחקנים
  ובמאים", ובעמוד האדם עצמו) מסמן שהוא/היא אהוב/ה עליכם. אין טבלת "אנשים"
  נפרדת באפליקציה - זו רשימה פשוטה של מזהי TMDb שסומנו.

## מגבלות ידועות / רעיונות להמשך

- אין ייבוא מ-IMDb/Letterboxd/Trakt (התבקש להתחיל מאפס עם הזנה ידנית).
- קוד הגישה הוא הגנה בסיסית בלבד, לא התחברות משתמשים אמיתית.
- אם רוצים תמיכה במספר צופים עם התחברות נפרדת, זה שינוי ארכיטקטורה לא קטן.
- הסכימה של מסד הנתונים השתנתה שוב במעבר הזה (טבלת `watch_events` חדשה
  במקום עמודת תאריך יחידה בטבלת `titles`). **אם כבר יש לכם `local.db` מגרסה
  קודמת, מחקו אותו** לפני שמריצים `npm run dev` מחדש, כדי שהאפליקציה תיצור
  מחדש את הסכימה הנכונה (זה מוחק את הנתונים המקומיים - אם יש לכם כאלה
  שחשוב לשמור, תגידו לפני שממשיכים).
- עמודת ה-`favorite` (הכוכבית) לעומת זאת מתווספת אוטומטית למסד נתונים קיים
  (`ALTER TABLE`) - אין צורך למחוק את `local.db` בשביל השינוי הזה.
